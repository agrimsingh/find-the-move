AI Engineer World's Fair 2026: Five Unconference Buckets

The strongest through-line was not "AI writes code." It was that teams are learning to operate agents as production systems: loops, harnesses, memory, verifiers, secure tool access, and agent-native interfaces.

01

Software Factories And The Agentic SDLC

From coding assistant to loop-running production system.

AI coding work is shifting into planning, coding, review, tests, deployment, and learning loops. The useful debate is whether teams should build literal factories, orchestras of agents, or a new engineering operating model.

Sessions: swyx on loopcraft; Jason Liu on Codex; Tereza Tizkova on software factories; Charlie Holtz on orchestras; Daksh Gupta on 1M AI-generated PRs; Dex Horthy on factory failure modes; Lee Robinson on recursive model improvement.

What should agents own first: tickets, PRs, tests, releases, or incident response?

02

Harnesses, Verifiers, And Trustworthy Agents

The cage around the model is becoming the product.

Capability is no longer enough. Production agents need evals, observability, session isolation, context contracts, sandboxes, auth, rollback, review, and kill switches.

Sessions: Tariq Shaukat on verifiers; Mike Chambers on the production cage; Katelyn Lesse and Angela Jiang on token jobs; Sarah Sanders on Bash-agent security; Kay Malcolm on database-backed memory; Microsoft on computer-use verifiers.

What is the minimum harness before an agent is allowed near production data?

03

Coding Agents Become Knowledge-Work Agents

Autoresearch is the clearest signal beyond coding.

The same patterns are moving into research, analytics, operations, compliance, and enterprise workflows. Agents read, experiment, evaluate, summarize, and try again.

Sessions: Richard Socher on automated research; Han Xiao on dense retrieval; Tim Sweeney on W&B autonomous research loops; Zhengyao Jiang on the OpenAI hiring challenge; Lakshya Agrawal on reflective optimization; Tejas Bhakta on kernels.

What non-coding workflow in your organization is ready for an agent loop?

04

Memory, Context, And Continual Learning

Bigger context windows do not solve remembering.

Agents need systems that decide what to keep, retrieve, compress, promote, and forget. Memory is not just a vector database, and storing facts is not the same as learning.

Sessions: Stefania Druga on long-running research-agent memory; Kay Malcolm on database-backed harnesses; Karthik Ranganathan and Heather Downing on supervised promotion; James Le on video memory; online talks on note memory, amnesia, code indexes, and continual learning.

What should agents remember privately, and what must be promoted to team knowledge?

05

Agent-Native Interfaces, Computer Use, And The New Web

Agents are becoming users of software.

Websites, APIs, auth flows, browsers, payments, and documentation need to be operable by agents while still leaving humans with control and receipts.

Sessions: Liad Yosef on rebuilding the web for agents; Nikita Kothari on MCPs, CLIs, and skills; Michael Grinich on auth.md; Miguel Gonzalez Fernandez and Corby Rosset on computer-use verifiers; agentic commerce sessions on wallets, x402, and protocol stacks.

If your next customer is an agent, what does your product need besides a nicer UI?
